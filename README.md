# AI-Powered Smart Career & Resume Assistant

An AI-powered web application designed to help students analyze their resumes, identify skill gaps, receive personalized career guidance, and prepare for interviews.

## Project Status

Currently under development.

## Planned Features

- User authentication
- Resume upload
- Resume text extraction
- Skill extraction
- Resume analysis
- Job-role matching
- Skill-gap analysis
- Personalized career roadmap
- Generative AI career assistant
- AI interview preparation
- Mock interview
